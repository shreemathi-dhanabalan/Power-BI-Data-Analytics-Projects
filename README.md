# Data Analytics Projects – Power BI

This repository showcases five data analytics projects completed as part of the Infosys–ICT Academy Finishing School for Employability program.

## Projects

### 1. Amazon Prime Video Analysis
Analyzed content distribution based on genres, countries, directors, release years, and content types.

**Tool:** Microsoft Power BI

**Project Demo:** [https://youtu.be/-DsCykEg9iw]

### 2. HR Analysis Dashboard
Analyzed employee demographics, gender distribution, departments, job roles, and workforce trends.

**Tool:** Microsoft Power BI

**Project Demo:** [https://youtu.be/dlGIbAwnCV8]

### 3. Student Details Dashboard
Analyzed student records using charts, graphs, and interactive filters.

**Tool:** Microsoft Power BI

**Project Demo:** [https://youtu.be/Esn8pbYtqGg]

### 4. Sales Person Performance Analysis
Explored salesperson performance, sales trends, geographic distribution, and product insights.

**Tool:** Microsoft Power BI

**Project Demo:** [https://youtu.be/P4SWtW32YCY]

### 5. IPL Analysis (2008–2025)
Analyzed team performance, player statistics, season trends, Orange Cap, and Purple Cap achievements.

**Tool:** Microsoft Power BI

**Project Demo:** [https://youtu.be/JntGzqrCf3Y]
